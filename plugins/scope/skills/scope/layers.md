# layers.md — the failure ladder (moved)

The failure ladder — why a green suite lies, and the addresses you type —
lives at **`docs/failure-ladder.md`** in the gherkin-node-test repository
(<https://github.com/bingh0/gherkin-node-test/blob/main/docs/failure-ladder.md>),
outside the plugin directory so that a plugin update cannot fork it and
other repositories have one stable address to link. It is versioned by
its specimens, so there is one copy; this file is a pointer. Read the
ladder there before handing the visionary the vocabulary.

The addresses, so the interview can type them without the file in hand:

- **hollow** (`cino:`, completion in name only — something exists, is
  green, and proves nothing): `cino:code`, `cino:binding`,
  `cino:assertion`, `cino:spec`, `cino:decision`.
- **absent** (`blind:`, never written at all): `blind:surface`,
  `blind:need`, and the candidate `blind:fenced` (a fence entry that
  declines a writer, 2026-10-30).

The dispatch question that names every rung, present and future:

> **Where does the lie live, and who wrote the ground truth?**

Each address carries its lie, its tell, its catch, and a dated specimen
in the canonical file; typing the address is the whole instruction.
